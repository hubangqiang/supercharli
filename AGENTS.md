# AGENTS Instructions for supercharli

Scope: applies to the entire `supercharli/` directory.

## Mission
Build SuperCharli as a local-first, identity-stable intelligent companion.

## Hard Constraints
- Keep product and engineering principles strictly separated.
- Do not weaken core temperament: optimistic, long-term, pragmatic, exploratory.
- Keep memory sovereignty local.
- Model adapters are replaceable; identity must remain continuous.

## Change Policy
- Update planning docs before expanding scope.
- Make minimal, reversible edits.
- Prefer clear architecture docs over hidden assumptions.

## Delivery Standard
- Every non-trivial change must include:
  - what changed,
  - why it changed,
  - impact on scope/performance/maintainability.
