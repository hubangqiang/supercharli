# Development Workflow

## Stage Gates
1. Freeze scope and acceptance criteria.
2. Implement minimal closed loop.
3. Reinforce and extend.

## Standard Flow
1. Clarify problem and boundary.
2. Update planning docs.
3. Implement minimal change.
4. Validate and record results.
5. Update handoff documents.

## Prohibited
- Expanding scope without scope-doc updates.
- Mixing product-principle changes with engineering refactors in one change.
- Declaring done without validation.
