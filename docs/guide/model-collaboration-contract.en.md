# Model Collaboration Contract

## Purpose
Keep consistent engineering language and quality baseline across different models.

## Required Inputs Before Work
- `persona.toml`
- principles documents
- scope and acceptance documents

## Required Outputs Per Change
- objective,
- impact scope,
- principle alignment,
- next recommendation.

## Consistency Rules
- Switching model must not switch principles.
- Switching model must not change project boundaries.
- Switching model must not break documentation structure.
