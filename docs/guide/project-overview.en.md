# Project Overview

## Goal
Build a local-first intelligent companion with stable identity and long-term evolution.

## Dual Governance
- Product governance: who SuperCharli is.
- Engineering governance: how SuperCharli is implemented and operated.

## Current Phase
V1 planning has been frozen and implementation is progressing.

## V1 Scope
- Included: basic conversation, identity stability, L1/L2 memory loop, model-agnostic routing.
- Excluded: external action execution, production multi-agent orchestration.
