# 类人记忆系统架构蓝图（SuperCharli）

## 目标
让 SuperCharli 的记忆不只是“存储更多内容”，而是具备类人的动态特征：
- 会忘：低价值信息自然衰减；
- 会重构：回忆后可更新，但可追溯；
- 会形成自我叙事：人格与长期记忆相互作用；
- 可控安全：不因“像人”而失真、胡编或越界。

## 总体分层（L0-L4）

## L0 感官痕迹（瞬时层）
- 用途：接收当前输入、上下文信号、情绪强度等短时特征。
- 保留：默认不持久化，仅用于本轮判断。
- 约束：禁止直接进入长期记忆。

## L1 事件记忆（会话层）
- 用途：保存当前/近期会话中的关键事件与行动链。
- 内容：事件、决策、动作、结果、情绪强度、时间戳。
- 生命周期：短周期高细节，按容量上限滚动淘汰。

## L2 模式记忆（规律层）
- 用途：沉淀跨会话可复用的“行为-结果”模式。
- 内容：触发条件、常见错误、有效策略、适用边界。
- 晋升：由 L1 候选经过评分与冲突检查后写入。

## L3 自传记忆（人生阶段层）
- 用途：记录长期阶段、关键转折、身份叙事变化。
- 内容：阶段目标、关键事件、阶段结论、连续性线索。
- 特点：低频更新，高解释力。

## L4 身份记忆（人格底座层）
- 用途：保存稳定价值观、人格底色、不可妥协边界。
- 内容：角色定义、行为原则、安全边界、长期使命。
- 特点：最稳定，变更必须可审计、可回滚。

## 记忆生命周期
1. 编码（Encode）：输入进入 L0，提取关键特征。
2. 写入（Write）：决策相关事件写入 L1。
3. 候选（Candidate）：L1 事件被评估为 L2/L3 候选。
4. 巩固（Consolidate）：离线任务将候选升级或降级。
5. 检索（Recall）：按预算召回最相关记忆进入本轮推理。
6. 重整合（Reconsolidate）：被回忆条目可形成“更新候选”。
7. 衰减与归档（Decay/Archive）：低价值条目降权并可逆归档。

## 晋升与遗忘机制

## 晋升评分（替代固定阈值）
- 评分维度：
  - 重复度（跨时间重复出现）
  - 影响度（是否改变决策或结果）
  - 可复用度（是否能用于未来类似场景）
  - 证据质量（是否有可验证结果）
  - 风险冲突（与现有记忆是否冲突）
- 只有评分达标才允许从 L1 晋升到 L2/L3。

## 遗忘与降权
- 使用“记忆强度”概念：`strength` 随时间衰减。
- 被成功检索并验证有效时增强强度。
- 长期低效条目进入可逆归档，而不是直接硬删除。

## 重整合安全（防记忆污染）
- 被召回的条目不直接覆盖原记录。
- 新信息先写入“更新候选”，通过冲突检查后再合并。
- 始终保留版本链，支持回放与审计。

## 检索策略（像人但可控）
- 召回预算：每轮最多 3-5 条高价值记忆。
- 检索信号：
  - 语义相关度
  - 最近性
  - 记忆强度
  - 当前严重等级（S0-S3）
  - 会话目标匹配度
- 重排目标：优先“当前可执行价值”，而非“字面最像”。

## 巩固任务（离线“睡眠”）
- 频率：每日或每 N 小时运行一次。
- 工作：
  - L1 -> L2/L3 候选压缩
  - 冲突检查与边界检查
  - 低价值条目降权/归档
  - 生成可读的记忆变化日志

## 与现有系统的兼容演进

## Phase 1（最小可落地）
- 在现有 L1/L2 上新增：
  - 晋升评分
  - 记忆强度与衰减
  - 检索预算（3-5条）

## Phase 2（中期）
- 引入：
  - 重整合候选区
  - L3 自传记忆表
  - 检索重排

## Phase 3（增强）
- 引入：
  - 语义向量检索
  - 周期性巩固作业编排
  - 记忆质量评估指标看板

## 数据主权与迁移
- 所有记忆默认本地存储，模型无隐藏记忆依赖。
- 导出/导入必须保留版本与元信息，确保人格连续。
- 迁移后应可重放关键记忆演化轨迹。

## 验收标准（类人记忆）
- 一致性：同类问题在不同模型下保持相近人格判断。
- 可解释：每条关键建议可追溯到记忆来源。
- 可进化：重要经历能改变风格权重，但不破坏人格底座。
- 可恢复：迁移到新环境后，记忆能力和人格连续性不丢失。
