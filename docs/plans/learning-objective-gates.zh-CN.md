# 学习目标函数与更新闸门（SuperCharli）

## 目标
确保学习模块提升真实效果，而不是“看起来更聪明”。

## 学习目标函数（Objective）

## 主指标（必须提升）
- 动作完成率（Action Completion Rate, ACR）
- 复发率下降（Recurrence Drop Rate, RDR）

说明：
- ACR 衡量建议是否被执行并完成。
- RDR 衡量同类问题是否减少重复出现。

## 副指标（不得恶化）
- 人格一致性分（Persona Consistency Score, PCS）
- 安全回归率（Safety Regression Rate, SRR）
- 用户负反馈率（Negative Feedback Rate, NFR）
- 延迟回归（Latency Regression, LR）

## 代理指标（用于调参）
- Prompt token 使用量（平均/分位）
- 记忆召回命中率
- 策略更新采纳率

## 学习事件分类
- `skill`：做事策略学习（动作序列、执行习惯）
- `style`：表达策略学习（语气、强度、收尾）
- `identity`：身份层学习（极低频，强审查）

规则：
- `skill/style` 可高频更新；
- `identity` 只允许候选，不允许自动生效。

## 更新闸门（Gates）

## G0 数据充分性闸门
- 最小样本：
  - `skill/style`：>= 30 有效事件
  - `identity`：>= 100 有效事件 + 人工审查
- 未达样本阈值：禁止更新。

## G1 质量收益闸门
- 在最近窗口（建议 7 天）：
  - ACR 提升 >= 5%
  - RDR 下降 >= 10%
- 任一不达标：禁止更新。

## G2 风险约束闸门
- PCS 不得下降超过 2%
- SRR 不得上升
- NFR 不得上升超过 1%
- 违反任一条件：禁止更新并触发回滚候选。

## G3 稳定性闸门
- 连续 2 个窗口满足 G1 + G2 才可放量。
- 首次仅灰度 10%-20% 会话。

## G4 合并闸门
- 灰度期通过后才可成为默认策略。
- 必须生成变更记录：版本、指标、影响范围、回滚点。

## 回滚策略
- 触发条件（任一）：
  - SRR 上升
  - PCS 下降超过阈值
  - 延迟 p95 超预算
- 回滚要求：
  - 一键切回上一版本策略
  - 保留失败样本用于根因复盘

## 实施建议（工程化）
- 先上线“候选更新 + 闸门评估”，后上线自动生效。
- 指标计算与策略生效解耦，避免同链路互相污染。
- 所有学习决策必须可追踪（trace id + evidence id）。
